anuraghazra/github-readme-stats의 calculateRank.js 공식을 그대로 구현합니다.

exponential_cdf(x) = 1 - 2^(-x) log_normal_cdf(x) = x / (1 + x) score = (stars×4 + prs×3 + commits×2 + issues×1 + followers×1) / 11 percentile = (1 - score) × 100

지표는 각각 중앙값(Stars:50, PRs:50, Commits:250/1000, Issues:25, Followers:10)으로 정규화된 후 CDF 함수를 거쳐 0~1로 변환됩니다.
