성현봇 (면진봇2)

GitHub 돌아가기

프로젝트 개요

성현봇은 면진봇의 후속작인 디스코드 경제 게임 봇입니다. 사용자는 도박, 주식·코인 투자, 무기 강화, 맞짱(PvP)으로 가상 코인을 벌고 소비합니다. 모든 명령어는 한글 슬래시 커맨드로 제공됩니다.

주요 기능 / 내용

  • 코인 수입: 10분마다 1,000 코인(/성현돈줘) · 자정 초기화 출석(/성현출첵)
  • 승률 30~60% 랜덤 도박, 결과는 ±베팅액(/성현도박)
  • 가상 주식·코인 투자, 3초 후 결과 공개(/성현주식, /성현코인)
  • 무기 강화(+30), 단계별 난이도 상승(/성현강화)
  • 맞짱(PvP): 무기 등급+랜덤 승부, 동일 금액 베팅(/성현맞짱)
  • 멤버 간 송금·파산 복구(/성현송금, /성현파산)
  • 프로필·서버 순위·관리자 메뉴(/성현프로필, /성현순위, /성현관리자)
  • SQLite 기반 사용자 데이터 저장(db.py + models.sql)
