프로젝트 개요

NFC 태그를 활용한 스마트 출석 체크 시스템입니다. 아두이노로 NFC 리더를 제어하고 라즈베리파이로 데이터를 처리 및 저장하는 IoT 구조로 설계했습니다.

주요 기능 / 내용

  • NFC 태그 인식 및 사용자 인증
  • 아두이노 RC522 NFC 모듈 연동
  • 출석 데이터 저장
  • 실시간 출석 현황 웹 대시보드
  • 아두이노 ↔ 라즈베리파이 시리얼 통신
  • 4x4 매트릭스 키패드로도 학번을 입력해 출석 가능
