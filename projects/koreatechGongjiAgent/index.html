프로젝트 개요

한국기술교육대학교(KOREATECH)를 위한 통합 알림 시스템입니다. 포털·생활관 공지를 자동 수집해 새 공지를 디스코드로 실시간 알리고, 메일(신규 수신 + 보낸 메일 수신확인)을 함께 감시하고, 도서관 열람실 좌석·셔틀버스 시간표·학식 메뉴 같은 캠퍼스 정보까지 제공합니다. 디스코드 봇·관리자 패널·개인 DM 구독·웹 대시보드·내부 FastAPI, 그리고 GPIO LED 상태 표시가 있는 라즈베리파이 빌드로 데이터를 제공합니다.

주요 기능 / 내용

  • 실시간 감지: 빠른 체크(기본 60초) + 전체 크롤링(기본 30분) 이중 주기 — 포털·생활관 게시판 순회, 한 게시판 실패 시 건너뛰고 계속
  • 디스코드 봇: /공지(드롭다운·페이지·임베드), 키워드 검색, 버튼식 통합 관리자 패널(/관리자 — 상태·수동 크롤링·재시작·Pi 화면/LED 조작·종료)
  • 개인 DM 구독(/구독) — 게시판·키워드별 새 공지 즉시 DM 또는 매일 요약, 일시정지/재개
  • 메일 알림(IMAP) — 코리아텍 메일을 폴링해 신규 수신 메일과 보낸 메일 수신확인을 개인 DM 알림(관리자 단일 계정, 자격증명 암호화, 기본 비활성)
  • 캠퍼스 정보 명령 — 다산정보관 열람실 실시간 좌석(/도서관), 실시간 셔틀 시간표·잔여 좌석(/셔틀), 학식 메뉴
  • 사용자용 읽기 전용 웹 대시보드(/web) + Cloudflare Quick Tunnel 외부 공개(선택)
  • 일정 파싱(날짜·시간·장소·카테고리) + 로컬 LLM(Ollama) 보조 분석(선택)
  • PySide6 GUI 대시보드 + 라즈베리파이: GPIO RGB LED 상태 표시, 7인치 터치 Pi 모드, systemd 자동 실행, 릴리즈 자동 업데이트
  • JSON + CSV 저장, 오래된 공지 자동 아카이브
