MultiMind

Python pyautogui tkinter RPA Multi-Agent
GitHub 돌아가기

프로젝트 개요

API 없이 pyautogui로 브라우저를 직접 조작해서 여러 LLM(Claude·ChatGPT·Gemini 등)에 동시에 프롬프트를 던지고 Head LLM이 Worker들의 답변을 종합해 최종 결과를 제공하는 GUI 기반 멀티 LLM 오케스트레이터입니다.

LLM마다 잘하는 영역이 다르기에 좋은 답변을 위해 여러 사이트에 프롬프트를 일일이 복붙하는 게 불편해서 만들었습니다.

시스템 아키텍처

① 사용자 — tkinter GUI에서 프롬프트 입력, Head/Worker 설정
↓
② Head LLM — 프롬프트를 Worker들에게 적합한 형태로 가공
↓ pyautogui 브라우저 자동 조작 (threading 병렬)
Worker
Claude
Worker
ChatGPT
Worker
Gemini
Worker
N...
↓ pyperclip으로 결과 수집
③ Head LLM — 수집된 답변들을 최종 합성
↓
④ 결과 출력 — tkinter GUI에 최종 답변 + 로그 기록

주요 기능

Head / Worker 자유 설정

  • GUI에서 Head LLM을 직접 선택 → 결과 합성 담당
  • Worker LLM 체크박스로 자유 구성 (Claude·ChatGPT·Gemini·Perplexity·Grok 등)
  • Head로 선택된 LLM은 Worker 목록에서 자동 제외
  • 설정값 json으로 저장 → 재시작 시 자동 복원

병렬 자동화 (입력 순차 + 대기 병렬)

  • pyautogui로 각 LLM 브라우저 탭 순차 입력 (각 2~3초)
  • 응답 대기는 threading으로 병렬 처리 → 시간 단축
  • 응답 완료 감지: 전송 버튼 재등장 이미지 인식 (locateOnScreen)

한글 입력 우회

  • pyautogui typewrite()는 한글 미지원
  • pyperclip.copy() + Ctrl+V 방식으로 해결

기존 유사 프로젝트와의 차별점

  • AutoChatScript / AutoChatgpt : 단일 LLM, 결과 종합 없음
  • TalkingHeads : 다중 LLM 지원하지만 결과 종합 기능 없음
  • WebAI-to-API : 복잡한 설치 필요 & 기술 난이도 높음
  • MultiMind : API 비용 0원, LLM 구성 자유 설정, Head가 최종 합성 → 전부 해결

확장 계획

  • 지원 LLM 추가 : Perplexity, Grok, HuggingChat 등
  • 질문 유형 자동 감지 → 최적 LLM 조합 추천
  • Worker별 답변 개별 확인 탭
  • 답변 히스토리 저장 및 검색
