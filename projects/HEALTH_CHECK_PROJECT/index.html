프로젝트 개요

사용자 맞춤형 헬스케어 데이터 관리 시스템입니다. 사용자가 건강 데이터를 직접 타이핑하거나, 음성 인식으로 입력해 시스템이 이를 분석하여 건강 상태를 모니터링하고 리포트를 제공합니다.

주요 기능 / 내용

  • 사용자 건강 데이터 입력 및 기록 (현재 상태)
  • 심박수 센서와 온도 센서로 사용자 상태 모니터링
  • 음성 인식과 TTS
  • 사용자 친화적 GUI (Tkinter)
  • 아두이노와 라즈베리파이 시리얼 통신
