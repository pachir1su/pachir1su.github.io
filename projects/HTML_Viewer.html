프로젝트 개요

HTML 코드를 붙여넣으면 즉시 결과물을 보여주는 가벼운 웹 뷰어입니다. 별도의 설치 없이 브라우저 안에서 마크업·스타일·스크립트를 바로 실행해 볼 수 있게 만드는 것이 목표입니다.

주요 기능 / 내용

  • HTML / CSS / JavaScript 통합 입력 에디터
  • 입력과 동시에 갱신되는 실시간 미리보기
  • 결과 화면 캡처 및 코드 저장
  • 코드 공유용 URL 생성 (예정)
