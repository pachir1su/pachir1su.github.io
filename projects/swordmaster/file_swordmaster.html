File Swordmaster

Python Gradio HuggingFace 개인 프로젝트
GitHub Swordmaster로

프로젝트 개요

File Swordmaster는 PDF와 오디오 파일을 다양한 방식으로 편집할 수 있는 다기능 파일 처리 스크립트입니다. Gradio를 UI 프레임워크로 사용하여 웹 인터페이스를 제공하며, 로컬 환경 및 Google Colab, HuggingFace Spaces에서 모두 실행 가능합니다.

2탭 구조(PDF / Audio)로 설계되어 직관적인 UX를 제공합니다. 복잡한 파일 처리 작업을 누구나 쉽게 할 수 있도록 CLI 없이 웹 UI만으로 제어할 수 있습니다.

주요 기능

  • PDF 분할 (페이지 범위 지정)
  • PDF 병합 (여러 파일 순서 병합)
  • PDF 워터마크 삽입
  • PDF 텍스트 추출 (OCR 포함)
  • 오디오 구간 분할 (타임스탬프 지정)
  • 오디오 N등분 자동 분할
  • HuggingFace Spaces 웹 배포 지원
  • Google Colab 실행 지원
