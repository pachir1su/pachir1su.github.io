Media Swordmaster

Python Gradio HuggingFace 개인 프로젝트
GitHub Swordmaster로

프로젝트 개요

Media Swordmaster는 이미지와 영상 파일을 위한 Gradio 기반 웹 앱으로, HuggingFace Spaces에 배포됩니다. 기존 File Swordmaster(PDF + 오디오)와 분리된 독립 앱으로, 이미지/영상에 특화된 4가지 기능을 제공합니다.

JPEG, PNG, WEBP, HEIC 이미지와 MP4, MOV, AVI, MKV 영상 파일을 지원하며, 메타데이터 편집부터 확장자 변환, GIF 생성, 워터마크 추가까지 미디어 처리에 필요한 핵심 기능을 하나의 앱에서 제공합니다.

주요 기능

메타데이터 편집

  • 이미지/영상 파일의 메타데이터 조회 (EXIF, GPS, 날짜/시간, 기기 정보, 해상도)
  • 필드별 값 수정 / 추가 / 삭제 후 파일 다운로드

확장자 변환

  • 이미지: JPEG ↔ PNG ↔ WEBP ↔ HEIC
  • 영상: MP4 ↔ MOV ↔ AVI ↔ MKV

GIF 만들기

  • 영상 파일을 GIF로 변환
  • 시작/끝 시간 지정, FPS 설정, 출력 해상도 조절

워터마크 추가

  • 이미지/영상에 텍스트 워터마크 삽입
  • 위치·날짜·모델명·폰트 크기·색상 커스터마이징
