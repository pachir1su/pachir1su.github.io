DelphiRec

GitHub 돌아가기

프로젝트 개요

DelphiRec은 멀티 전문가 페르소나와 델파이 기법을 결합한 AI 기반 생활기록부 분석· 질의응답 시스템입니다. 시중 프로그램이 분석만 해주는 게 아쉬워서 만들었습니다. 실제 입학사정관 · 교수진의 시각에서 생기부를 평가하는 것이 목표입니다.

기획 배경

기존 생기부 분석 서비스는 요약 및 피드백 출력, 점수 매기기에 그칩니다. DelphiRec은 전문가 집단의 토론을 시뮬레이션하고 두 가지 평가 방법론(토론 · 델파이)을 선택할 수 있도록 설계하여 사용 목적에 따라 효율적으로 사용할 수 있습니다.

핵심 기능

1. 생기부 입력 및 전처리

  • 텍스트 · 이미지 · PDF 등 다양한 형식 입력 지원
  • OCR 및 구조화 파싱을 통한 데이터 정제

2. 전문가 페르소나 시스템

  • 분야별 전문가 프로필(학력 · 논문 · 프로젝트 등) 사전 등록
  • 사용자 커스텀 페르소나 설정 (목표 학교 · 학과 맞춤형 평가)

3. 분석 모드 (토글 전환)

  • 토론 모드 — 페르소나 간 실시간 의견 교환 및 반박, 채팅 버블 UI로 다양한 시각의 날것 의견 제공
  • 델파이 모드 — 익명 개별 평가 후 라운드별 수렴 반복, 합의된 정제 피드백을 리포트 형식으로 제공

4. 실시간 질의응답

  • 분석 결과를 컨텍스트로 유지한 채 사용자와 대화
  • 특정 페르소나를 지목한 질문 가능
  • 면접 시뮬레이션으로 자연스럽게 확장

차별점

  • 단순 분석을 넘어 전문가 집단 토론 시뮬레이션 제공
  • 두 가지 평가 방법론(토론 · 델파이) 선택 가능
  • 커스텀 페르소나로 목표 학교 · 학과 맞춤형 평가
  • 질의응답 연계로 생기부 분석에서 면접 준비까지 원스톱

개발 범위 (MVP)

  • 생기부 PDF 파싱 및 구조화
  • 기본 페르소나 3종 이상 구성
  • 델파이 모드 2라운드 수렴 구현
  • 토론 모드 채팅 UI 구현
  • 최종 질의응답 인터페이스
