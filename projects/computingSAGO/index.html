프로젝트 개요

매일 아침 날씨·뉴스·미세먼지 정보를 Gemini AI가 종합하여 Discord 채널에 자동으로 브리핑해주는 서비스입니다. 자동화되어 사용자 개입 없이 지정 시간에 리포트가 발송됩니다.

슬래시 커맨드로 즉시 리포트를 요청하거나 날씨·뉴스를 단독 조회할 수 있고 Gemini에게 자유 질문도 가능합니다. 설정값은 config.json에 저장되어 시간·지역을 언제든 변경할 수 있습니다.

주요 기능

① 매일 아침 자동 브리핑

  • 매일 지정 시간(기본 오전 7시)에 자동 실행
  • 날씨·미세먼지·뉴스 수집 후 Gemini가 리포트 생성
  • Discord 개인 디엠으로 자동 발송

② Discord 슬래시 커맨드

  • /리포트 — 즉시 리포트 생성
  • /날씨 — 현재 날씨 조회
  • /뉴스 — 최신 뉴스 요약
  • /질문 [내용] — Gemini에게 자유 질문

③ 브리핑 내용

  • 오늘 날씨 + 기온
  • 미세먼지 등급
  • 주요 뉴스 3건 요약

④ 사용자 설정

  • /설정 시간 [HH:MM] — 브리핑 시간 변경
  • /설정 지역 [지역명] — 날씨 지역 변경
  • 설정값은 config.json에 저장
