프로젝트 개요

온라인담타 사이트를 벤치마킹하여 기획한 술담(술 + 담배) 사이트입니다.

별도 서버 없이 GitHub Pages로 배포할 예정이므로 순수 HTML/CSS/JS와 브라우저 기반 기술만으로 최대한의 기능을 구현하는 것이 목표입니다.

주요 기능 / 내용

  • 야무진 술담배 UI/UX 디자인
  • GitHub Pages 정적 사이트 배포
  • 온라인담타 벤치마킹 기반 기능 설계
  • 서버 없이 동작하는 프론트엔드 중심 구현
