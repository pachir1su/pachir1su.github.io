프로젝트 개요

라이어게임, 양세찬게임, 마피아게임 등의 미니게임 봇

기존 면진봇의 완전 개편 버전입니다. 기존 코드베이스를 전면 재설계하여 더 안정적이고 확장 가능한 시스템으로 새롭게 구축할 예정입니다.

기존 면진봇에서 운영하면서 발견한 구조적 문제점과 사용자 피드백을 반영해 단순한 패치가 아닌 완전한 리빌드 형태로 진행할 예정입니다.

주요 기능 / 내용

  • 기존 시스템 전면 재설계
  • 기존 대비 다수의 신규 게임 기능 추가 예정
