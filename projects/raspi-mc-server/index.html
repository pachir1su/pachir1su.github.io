라즈베리파이 마인크래프트 서버

PythonJavaDiscord.pyPaperMCGeyser개인 프로젝트
GitHub 돌아가기

프로젝트 개요

라즈베리파이 4B(4GB)와 3~4명 규모에 맞춘 친구 전용 마인크래프트 서버입니다. 하나의 PaperMC 월드에서 Java 플레이어와 Geyser·Floodgate를 통한 선택형 Bedrock 크로스플레이를 지원합니다. 오너 전용 디스코드 제어판에 서버 관리·친구 온보딩·복구·월드 저장소·자체 Paper 플러그인을 통합하고, SSH와 RCON은 기본 운영 경로로 유지합니다.

주요 기능 / 내용

  • Pi 4B 4GB에 맞춰 튜닝한 PaperMC(Aikar GC 플래그, Pi에 맞춘 view/simulation distance), 32GB microSD + 500GB USB HDD 구성
  • Geyser + Floodgate 선택형 Java·Bedrock 크로스플레이 — 친구는 주소를 한 번 저장해 같은 Paper 월드에 접속
  • 운영자 레벨 기반 오너 전용 치트: 콘솔·RCON·디스코드 봇·SSH는 항상 op 레벨 4로 동작 — 오너만, 원격으로 치트 가능
  • 디스코드 제어판: 관리자·공개 패널, 친구 계정 연동, 빠른 명령, 로딩 피드백, 쿨다운, 감사 로그, 건강 점수
  • 원격 접속: 기본 SSH + RCON 콘솔, 선택적으로 Cloudflare 터널(포트 포워딩 불필요)
  • 30분 주기 HDD 백업 + SHA-256 검증, 오프라인 안전 복원, 디스코드 맵 업로드·전환, 백업 정책 설정과 타임라인
  • 번들 Paper 플러그인: 보호형 Death Box와 컨테이너 잠금·인챈트·스폰 보호·소환 운영 기능
  • 친구용 도구: 플레이어 연동, 공개 상태, 구조 기능, 장소, 일지, 다국어 명령 안내
  • 운영 도구: 자동 성능 경고, 튜닝 리포트, 원클릭 장애 대응, 접속자 조회, 순환 감사 로그, 업데이트 관리
  • systemd 자동 실행, 원샷 프로비저닝 스크립트, 선택적 라즈베리파이 클러스터 가이드
  • 영어·한국어 이중 문서 제공

나의 역할

1인 개발

  • 서버 설정·튜닝(PaperMC, 운영자)
  • 디스코드 관리봇 개발(RCON 제어)
  • Paper 플러그인 개발(Death Box·서버 운영 기능)
  • 배포·프로비저닝 스크립트(Bash, systemd)
  • 백업·원격 접속 구성(SSH/RCON, Cloudflare 터널)
  • 영어·한국어 문서화
