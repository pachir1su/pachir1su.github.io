프로젝트 개요

라즈베리파이 4B(4GB)와 3~4명 규모에 맞춘 친구 전용 마인크래프트(Java / PaperMC) 서버입니다. 치트는 오너만 사용할 수 있습니다. 명령어가 운영자(op) 레벨로 제한되어, 다른 사람은 게임 안에서 치트를 못 쓰고 저는 어느 관리 채널로든 원격으로 항상 쓸 수 있습니다. 서버는 세 가지 방식으로 관리합니다. 관리자 전용 슬래시 명령을 제공하는 디스코드 봇(메인), 기본 콘솔인 SSH + RCON, 포트 포워딩 없이 접근하는 Cloudflare 터널(선택)입니다. 문서는 영어와 한국어로 함께 작성했습니다.

주요 기능 / 내용

  • Pi 4B 4GB에 맞춰 튜닝한 PaperMC(Aikar GC 플래그, Pi에 맞춘 view/simulation distance), 32GB microSD + 500GB USB HDD 구성
  • 화이트리스트 전용·모드 없음 — 친구 몇 명을 위한 작은 사설 월드
  • 운영자 레벨 기반 오너 전용 치트: 콘솔·RCON·디스코드 봇·SSH는 항상 op 레벨 4로 동작 — 오너만, 원격으로 치트 가능
  • 디스코드 관리봇(메인): 관리자 전용 슬래시 명령, 버튼 중심 대시보드, 느린 작업용 로딩 애니메이션, 로그 파일 첨부
  • 원격 접속: 기본 SSH + RCON 콘솔, 선택적으로 Cloudflare 터널(포트 포워딩 불필요)
  • 30분 주기 HDD 백업 + SHA-256 검증, 디스코드 복원·맵 업로드·전환, 백업 타임라인
  • 운영 도구: 자동 성능 경고, 튜닝 리포트, 원클릭 장애 대응 헬퍼, 접속자 인벤토리 조회, 헬스 체크, 순환 감사 로그
  • systemd 자동 실행, 원샷 프로비저닝 스크립트, 선택적 라즈베리파이 클러스터 가이드
  • 영어·한국어 이중 문서 제공

나의 역할

1인 개발

  • 서버 설정·튜닝(PaperMC, 운영자)
  • 디스코드 관리봇 개발(RCON 제어)
  • 배포·프로비저닝 스크립트(Bash, systemd)
  • 백업·원격 접속 구성(SSH/RCON, Cloudflare 터널)
  • 영어·한국어 문서화
