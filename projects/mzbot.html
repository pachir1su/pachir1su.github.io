MZ_bot

GitHub 돌아가기

프로젝트 개요

디스코드 서버 사용자들을 위한 경제 게임 봇입니다. 사용자들이 서버 내에서 가상 화폐를 획득하고 소비하는 경제 시스템을 구축하여 커뮤니티 활성화에 기여합니다.

주요 기능 / 내용

  • 가상 화폐(코인) 획득 및 소비 시스템
  • 출석 체크 일일 보상 기능
  • 사용자 간 코인 송금 기능
  • 상점 시스템 (아이템 구매/판매)
  • 순위표 (리더보드) 기능
  • SQLite 기반 사용자 데이터 영속 저장

개발 과정 & 배운 점

Discord.py 라이브러리를 처음 학습하고 실제로 사용 가능한 봇을 만들면서 비동기 프로그래밍(asyncio)과 이벤트 기반 아키텍처를 이해했습니다. 데이터 영속성을 위해 SQLite를 적용하며 데이터베이스 활용 경험도 쌓았습니다.
