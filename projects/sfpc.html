프로젝트 개요

총 581팀 / 1661명이 참가한 알고리즘 대회 SFPC(Software Festival Problem Challenge)에서 전체 8위(Top 1.3%)를 기록한 코드 아카이브입니다. 다양한 알고리즘 문제를 팀과 협업하여 효율적으로 해결했습니다.

주요 기능 / 내용

  • 581팀 중 전체 8위 (Top 1.3%) 달성
  • 다양한 알고리즘 문제 풀이 코드 수록
  • C++ 및 Python 언어 활용
  • 팀 전략 수립 및 역할 분담
  • 시간 복잡도 최적화 문제 해결
  • 그래프, DP, 수학, 완전탐색 등 다양한 유형 대응

개발 과정 & 배운 점

제한된 시간 안에 복잡한 알고리즘 문제를 팀원들과 빠르게 분업하여 해결하는 경험을 했습니다. 581팀 중 8위를 기록하며 알고리즘 문제 해결 능력과 팀 협업 능력을 동시에 증명했습니다.
