CentrifugeAI

Python Flask Gemini API Discord Bot 개발 중
GitHub 돌아가기

프로젝트 개요

콧물을 원심분리기에 돌리면 어떻게 될 지 궁금해서 만들어 봤습니다. 사용자가 임의의 재료를 고르고 실험 장치에 투입하면 Gemini API가 결과를 예측해 출력합니다.

결과는 텍스트로만 출력되지 않고 층 분리 이미지·SVG 그래프·결과 카드 형태로 출력되어 실제 실험 느낌을 제공합니다. 모든 실험 기록은 SQLite에 영속화되어 히스토리 조회와 재생(Replay)이 가능합니다.

Flask 기반의 웹 인터페이스와 함께 Discord Slash Command 기반 봇도 동시에 지원해 어디서나 쉽게 실험을 돌릴 수 있도록 설계했습니다.

주요 기능

다양한 가상 실험 장치

  • 원심분리기 — 층 분리 시뮬레이션
  • 화학 반응기 — 반응 예측 및 부산물 생성
  • 현미경 — 미시적 구조 시각화
  • 가열/냉각기 — 상태 변화 추적
  • 믹서기 / 압력솥 / 전자레인지
  • 입자 가속기 — 극한 조건 실험

Gemini AI 기반 결과 생성

  • 물질의 반응 예측
  • 분리 결과 및 상태 변화 설명
  • 실험 결과 JSON 구조화

실험 결과 시각화

  • 층 분리 이미지 자동 렌더링
  • SVG 기반 결과 그래프
  • 시각적 결과 카드 출력

실험 기록 저장

  • SQLite 기반 히스토리 영속화
  • 이전 실험 조회 및 재생(Replay)

웹 + 디스코드 동시 지원

  • Flask 기반 웹 UI — 실험 선택 / 결과 확인 / 히스토리
  • Discord Slash Command 기반 실험 봇

추가 예정 기능

  • 실험 히스토리 UI 개선
  • 실험 결과 공유 기능
  • 사용자 커스텀 실험 제작
  • 실시간 애니메이션
  • 3D 시각화
  • 모바일 최적화
