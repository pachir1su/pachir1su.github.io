마법 아카데미

Simulation Interactive Visualization 진행 예정
돌아가기

프로젝트 개요

원소를 조합해 마법을 만들고 결과를 시각화하는 인터랙티브 시뮬레이션입니다. 기초 원소(불·물·바람·흙 등)에서 시작해 조합 규칙에 따라 점차 복잡한 마법으로 확장되는 샌드박스를 목표로 합니다.

주요 기능 (예정)

  • 원소 조합 시스템 — 예 : 불 + 물 → 수증기
  • 마법 효과 실시간 시각화 (파티클, 컬러 변화)
  • 단계적 난이도 — 기본 원소에서 복합 마법으로 확장
  • 발견한 마법 컬렉션 / 도감

설계 메모

원소 간 조합 규칙은 데이터 테이블로 분리해 쉽게 확장 가능하도록 만들 예정입니다. 시각화 레이어는 p5.js 혹은 Canvas 기반으로 가볍게 구성하고, 가능하다면 모바일 터치 인터랙션까지 고려합니다.

Tech Stack (예정)

Python (예정) p5.js (예정) Canvas / SVG
