프로젝트 개요

한국기술교육대학교 캠퍼스의 지도를 웹으로 구현하는 프로젝트입니다. 학교 대피도를 참고하거나 직접 탐사, 혹은 시설팀으로부터 공식 지도를 받아 데이터 구축 예정입니다. 건물 전체 지도와 각 건물 내부의 층별 구조와 호실 정보를 담을 예정입니다.

건물 또는 호실을 클릭하면 애니메이션과 함께 부드럽게 상세 정보로 전환되는 인터랙티브 UX를 설계할 예정입니다.

주요 기능 / 내용

  • 한기대 캠퍼스 전체 지도 시각화
  • 각 건물 내부 층별 지도 및 호실 구조 출력
  • 호실별 담당자 연락처 정보 제공
  • 건물 · 호실 클릭 시 애니메이션으로 부드럽게 전환
  • 대피도 데이터 참고 및 직접 탐사 기반 데이터 구축
  • 시설팀 협조를 통한 공식 지도 데이터 확보 시도
