# v2.6.x Freeze / Refactor

v2.6.0 `Final Note` 발행 이후 v3에 들어가기 전에 수행하는 **한 번의 큰 안정화 작업**입니다. 작은 수정 PR을 연속으로 만들지 않고, 정적 소스 정리·실제 기기 반응형 QA·성능 회귀 확인을 하나의 Freeze 범위로 묶습니다.

## 목표

1. v2.6.0에서 사용자 화면에 적용된 정규화 결과를 정적 HTML/CSS로 굳힙니다.
2. #123/#16의 반응형·성능 요구를 실제 화면 크기와 입력 방식에서 확인합니다.
3. v3 디자인 작업 전에 v2 계열의 기술 부채와 임시 호환 코드를 제거합니다.
4. `projects.json` → `build.js` → `index.html` 생성 계약을 깨지 않은 상태에서 Freeze 합니다.
