## Finalization 단계

`agent/v2.6-finalization` PR을 v2.6.0 직전 마지막 개발 PR로 사용합니다. 이 PR이 `main`에 머지되면 GitHub runner가 다음 4개 원자 커밋을 추가합니다.

1. `index.html` 정적 마크업 최종 정리
2. `style.css` obsolete interaction CSS 제거 + 반응형 마무리
3. `script.js` 임시 DOM normalizer 제거
4. finalization workflow 자기 제거

검증에 실패하면 `main` push 단계까지 진행하지 않도록 구성합니다.

## 검증 원칙

- `projects.json`을 프로젝트 카드의 단일 소스로 유지
- `BUILD:PROJECTS` 생성 영역 직접 수정 금지
- PR 내부는 변경 파일 수와 커밋 수를 동일하게 유지하고 파일당 정확히 1커밋
- 공개 저장소에서 개발자 도구·우클릭·텍스트 선택 차단 금지
- `node --check script.js`
- `node build.js` 실행 후 무변경 확인
- `node tools/verify-build.js`
- `git diff --check`
- 실제 브라우저/기기 QA를 하지 못한 항목은 통과했다고 표시하지 않음

## Release gate

Finalization workflow가 성공해 `main`에 4개 소스 정리 커밋이 반영되고 정적 검증 결과를 재확인하면 `v2.6.0` 태그/Release를 생성합니다. 이후 v2.x는 Freeze 단계로 전환합니다.
