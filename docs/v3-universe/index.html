v3 우주

v3은 v2의 교체가 아니다. v2가 정보를 맡고 우주가 세계관을 맡는다. 두 공간은 v2 홈에 뚫린 찢긴 종이 구멍 하나로만 이어진다.

구현은 시안 폴더를 떠나 운영 경로 /universe/에 있다. 이 폴더는 그 설계 기록이다 — 무엇이 확정이고, 무엇을 왜 버렸고, 무엇이 아직 미확정인지.

운영 index.html에 들어간 것은 히어로의 .v3-gate-host 한 줄과 시트 하나 · 스크립트 하나뿐이다. style.css · script.js · projects.json과 BUILD:PROJECTS 생성 영역은 건드리지 않았고, 프로젝트 데이터는 projects.json을 읽기만 한다.

지금 보고 있는 것

이동 방식 다 · 세로로 흐르는 하늘을 골라 완성본으로 지었다. 비교 시안 셋은 아래에 그대로 남긴다 — 무엇을 보고 골랐는지가 근거이기 때문이다.

들어가는 문 — gateway.html

여기서 시작한다. v2 홈의 종이에 뚫린 찢긴 구멍 하나가 우주로 이어진다. 새로고침마다 자산 · 위치 · 크기 · 기울기가 달라지고, 별과 먼지가 찢긴 경계 밖으로 조금 새어 나온다. 누르면 약 4초 동안 별가루가 구멍으로 빨려 들어가며 문이 열린다. 이름표도 확인창도 없다. 운영 universe/gate.css · gate.js를 그대로 읽는다.

우주 — universe.html

문서가 평범하게 세로로 스크롤되고, 하나의 하늘이 위에서 아래로 계속 이어진다. 깊이가 다른 세 층이 다른 속도로 지나가므로 내려갈수록 실제로 이동하고 있다는 감각이 남는다. 스냅도 정거장도 진행 안내도 없다. 프로젝트 이름은 언제나 화면에 있다.

내려가는 순서 — 문 앞의 별자리(새로고침마다 북두칠성/전갈자리 50:50) → 2026 → 2025 → 2024 → 궤적 → 표류 → 기록. 궤적은 순서대로 이어야 선이 금빛이 되고 C → A가 오른다. 별을 누르면 역할·설명·기술·상세 링크가 펼쳐지고, 상태는 글자가 아니라 형태로만 말한다. 한국어/영어를 전환할 수 있고 테마는 운영체제 설정만 따른다. 이스터에그는 예고하지 않는다.

무엇을 보고 골랐나 — 이동 방식 비교

우주 안에서 어떻게 이동하는가는 2026-08-19부터 정해진 적이 없었다. #114에 카메라 이동은 구체적인 작동 예시를 본 뒤 판단으로 남아 있고 그 비교가 끝내 이뤄지지 않았다. 아래 셋은 같은 데이터 · 같은 시각 언어 · 같은 정보 규칙 위에서 이동만 다르게 만든 것이다. 셋 다 프로젝트 이름이 항상 화면에 있다.

다 · 세로로 흐르는 하늘 (채택)

평범한 세로 스크롤. 다만 섹션이 끊긴 게 아니라 하나의 하늘이 위에서 아래로 계속 이어진다. 정거장 · 스냅 · 진행 표시 · 다음 안내가 없다. 축이 하나뿐이라 길을 잃지 않고, #123 기기 목록 전부에서 조작이 같다.

나 · 이어진 하늘

하늘이 상하좌우로 이어진다. 끌면 끌리고, 휠 · 방향키 · +/−가 전부 같은 카메라를 민다. 여행감이 가장 크지만 2차원이라 길을 잃을 수 있다. 오른쪽 아래 작은 지도는 지금 화면이 하늘의 어디인지만 보여 준다.

가 · 서서 보기 (기준선)

2026-08-20에 승인된 무대 그대로다. 한 화면 고정, 오른쪽 축에서 구역을 고르면 그 자리에서 하늘이 다시 짜인다. 이동이 없다. 나머지가 이보다 나은지 보려고 같이 둔다.

셋이 지키는 규칙 둘. 아무것도 가로채지 않는다 — 스크롤·드래그는 입력 그대로 카메라를 옮기고 자동 스냅·정거장·진행 표시를 두지 않는다. 아무것도 숨기지 않는다 — 어느 위치·어느 배율에서도 프로젝트 이름이 화면에 있다. 공용 엔진은 move.js · move.css이고 렌더는 운영 universe/sky.js를 그대로 읽는다.

구현은 어디에 있나

시안이 아니라 사이트의 일부다. 아래 두 곳이 운영 경로다.

별자리 공간 — /universe/ (보류)

눌러서 날아가는 3차 구현이다. 멀리서 프로젝트 이름이 하나도 안 보여 2026-08-20에 확정된 정보 규칙을 어겼으므로 v3.0.0 후보에서 내려갔다. 실패 기록으로 남긴다. 이동 방식이 정해지면 이 경로를 다시 쓴다. 렌더 엔진 sky.js는 위 시안 셋이 그대로 쓰고 있다.

진입점 — 홈 히어로

찢긴 종이 구멍 하나가 v2와 v3을 잇는다. 운영 index.html의 .v3-gate-host 한 줄과 universe/gate.css · universe/gate.js가 전부다.

시각 언어 — design-system.html

팔레트 · 타입 · 모션 · 천체 폼 · 안티패턴을 한 장에서 본다. 운영 시트를 그대로 읽는다.

물린 안 — voyage.html

스크롤로 항해하던 시안. 물렸다. 스크롤은 정해진 길을 따라가는 것이고, #114에서 좋다고 한 것은 전부 직접 만지는 조작이었다. 근거로만 남긴다.

로컬 확인에는 정적 서버가 필요하다. file://로 직접 열면 fetch가 막혀 프로젝트 데이터가 비어 보인다. 저장소 루트에서 python3 -m http.server를 띄우고 /universe/로 들어간다.

확정

#114의 취향 캘리브레이션과 이후 판정에서 사용자가 직접 고른 값이다.

구조v2 유지 + 별도 우주 공간. 진입점은 v2 홈의 찢긴 종이 구멍 하나
배경엷은 성운 — 화면 밖 오른쪽 위 방향광 · 어두운 먼지 띠 · 입자 2층

구도왼쪽 아래 이름 · 오른쪽 위 별자리 (대각선)

폐기

실패한 실험도 근거로 남긴다. 다만 다시 가져오지 않는다.

수묵 방향배경 BG-A 탈락과 함께 아트 디렉션 전체 폐기
그레인 필드BG-C 탈락. 재질용 미세 입자만 성운 위에 남긴다
점선LN-C 탈락. 아직 잇지 않은 구간은 어두운 실선으로 표시한다
지평선 구도CP-C 탈락. 이후 모든 장면에서 쓰지 않는다
명조체 서체용어 정정 — 사용자가 말한 「명조」는 서체가 아니라 게임이다
이름표 CONSTELLATION진입점에서 제거. 조작 안내와 확인창도 두지 않는다
화면 위 상태 글자진행 중 · 실패를 쓰지 않는다. 형태로만 구분한다
선형 카피바라외곽선 연결은 곤충처럼 읽힌다. 입자 실루엣만 쓴다
가상 해안 장벽 시뮬레이터실제 동작과 달라 폐기. 상세는 운영 페이지로 보낸다
관측창 + 목록 (모델 A)오른쪽 목록이 곧 프로젝트 카탈로그다. v2와 같은 물건이 된다 — 카탈로그는 v2의 일이다
스크롤 항해voyage.html. 스크롤은 정해진 길을 따라가는 것이라 만지는 감각이 없다
좁은 화면 번호 범례정보를 목록으로 강등하는 것은 #10의 반대다. 어느 폭에서도 조작이 같다

버전과 반영 순서

이 작업은 v3.0.0이다(#120). 기준은 루트 README.md의 버전 기록과 docs/v3.0.0-release-notes.md다. Git tag와 GitHub Release는 만들지 않는다.

반영 순서는 v2 마감 → v3.0.0이다. #249에 v3은 v2 완전 마감된 이후 개발 및 반영 예정으로 기록되어 있다. 이 릴리즈는 v2의 어떤 화면도 되돌리지 않으므로 v2 마감 작업과 충돌하지 않는다.
