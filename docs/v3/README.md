# v3 — 디자인 · UIUX 명세 (`docs/v3/`)

이 폴더는 v3의 **전부**를 한곳에서 구현한 작업 폴더다.
이전 실험 기록(`docs/v3-constellation-prototypes/`, `docs/v3-mockups/` 등)은 근거로 보존하고,
여기서는 이슈 #114에 누적된 확정 사항만 골라 하나의 동작하는 시안으로 합친다.

운영 파일(`index.html`, `style.css`, `script.js`, `projects.json`)은 이 폴더에서 수정하지 않는다.
데이터는 저장소 단일 소스 `projects.json`을 **읽기만** 한다.

---

## 0. v3의 정의 (#114 · 2026-08-20 확정)

v3은 v2 포트폴리오의 교체가 아니다.

| 공간 | 역할 | 상태 |
|---|---|---|
| **v2 노트 포트폴리오** | 정보. 이름 · 정체성 · 프로젝트 32개 · 수상 · 연락처 | 유지 |
| **v3 우주** | 세계관. 별자리로 읽는 프로젝트 · 성장 · 실패 · 이스터에그 | 신규 |

두 공간은 v2 홈에 뚫린 **찢긴 종이 구멍** 하나로만 이어진다.
`포트폴리오니까 다 보여야 한다`와 `개성 있는 세계관`이 한 화면에서 충돌하던 문제가 이 분리로 사라진다.

## 1. 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 시안 허브. 무엇이 확정이고 무엇이 미확정인지 |
| `gateway.html` | v2 홈 위에 얹은 우주 진입점. 실제 `style.css`를 불러 v2 재질 위에서 확인 |
| `universe.html` | 우주 본편. 연도 별자리 · 성장 별자리 · 궤도를 잃은 별 · 이스터에그 |
| `v3.css` | 공용 시각 언어 · 반응형 · 모션 |
| `v3.js` | 공용 엔진. 성운 렌더 · 성도 배치 · 상호작용 · 사운드 · 이스터에그 |

`gateway.html`과 `universe.html`은 `../../projects.json`을 `fetch`한다.
로컬 확인은 파일 열기(`file://`)가 아니라 정적 서버가 필요하다.

## 2. 확정된 시각 언어 (#114 취향 캘리브레이션)

| 축 | 확정 |
|---|---|
| 배경 | 엷은 성운 — 방향광 + 어두운 먼지 띠 + 입자 2층 |
| 별 | 3계층 — 먼 먼지 300+ / 일반 별 70(순수한 점) / 별자리 별(옅은 달무리) |
| 선 | 낡은 금빛 실선. 굵기 1.1px · 불투명도 0.6 안팎 |
| 서체 | IBM Plex Sans KR. 이름은 얇은 200을 크게, 영문은 자간을 넓게 |
| 구도 | 왼쪽 아래 이름 · 오른쪽 위 별자리 (대각선) |
| 팔레트 | 라이트 `#e8eaf2` + `#706994` / 다크 `#11151d` + `#968dbb` / 금빛 `#a9914d` |
| 테마 | 수동 토글 없음. 시스템 설정만 따른다 |
| 언어 | `data-ko` / `data-en` 유지. KO / EN 전환은 우주에도 둔다 |

### 회피 확정 (안티패턴)

1. 네온 글로우 + 순검정 배경
2. 둥근 알약 · 칩 남발
3. 같은 크기 카드 반복 배치
4. 균일하게 흩뿌린 별 + 영문 대문자 키커 + 이스터에그 사전 안내
5. 화면 위 상태 글자(`진행 중` · `실패`) — 형태로만 구분하고 `aria-label`에만 남긴다

## 3. UIUX 계약

포트폴리오가 세계관보다 먼저다. #114의 `프로젝트가 다 보이긴 해야 함. 눌러야 보이는 게 아니고`가 기준이다.

1. **1차 정보는 항상 보인다.** 프로젝트 이름은 전부 상시 표시된다.
2. **2차 정보만 접는다.** 역할 · 한 줄 설명 · 상세 링크만 눌렀을 때 펼쳐진다.
3. **펼쳐도 성도는 움직이지 않는다.** 별의 좌표와 별자리 선은 개폐와 무관하게 고정이다.
   펼친 설명은 별 버튼의 레이아웃 밖 메모 레이어에 그린다.
4. **한 번 더 누르면 상세 페이지로 간다.** 카드 안에 `상세 보기`를 명시한다.
5. **연도별 별자리 형태는 서로 겹치지 않는다.** 2026 · 2025 · 2024는 각각 다른 성도를 쓴다.
6. **완료된 별만 별자리를 이룬다.** 진행 중 · 궤도를 잃은 별에는 선이 없다.
7. **상호작용 요소는 겹치지 않는다.** 폴드 · 모바일 · 태블릿 · 노트북 · 데스크톱 각각의 성도를 따로 두고,
   렌더 후 실제 사각형으로 충돌을 검사해 라벨 쪽을 밀어낸다.
8. **돌아가는 길에 글자를 쓰지 않는다.** 작은 빈 포스트잇 하나만 둔다.

## 4. 상태 → 천체 대응

`projects.json`의 실제 상태가 그대로 별의 생애에 대응한다. 글자 라벨은 쓰지 않는다.

| 실제 상태 | 천체 | 형태 |
|---|---|---|
| 완료 | 주계열성 | 또렷한 점 + 옅은 달무리. 별자리 선에 참여 |
| 기획 단계 | 원시성 | 강착 원반만 돌고 코어는 속이 빈 윤곽 |
| 개발 중단 | 점화 실패 | 코어가 어둡게 맥동 |
| 실패 | 초신성 잔해 | 껍질이 퍼지고 군데군데 끊김. 중심이 비어 있음 |
| 지연 (한기대 지도 초기 버전) | 궤도 이탈 | 별은 살아 있고 끊어진 궤도 흔적만 남음 |
| 격리 (BrawlCraft) | 제51구역 | 일반 화면에 올리지 않는다 |

`한기대 지도`는 실패한 초기 버전, `한맵`은 그 후속 기획이다. 관계는 펼친 설명에서만 밝힌다.

## 5. 진입 연출 (v2 → v3)

- 확인창(`confirm`)을 쓰지 않는다.
- 새로고침 · 재진입마다 찢긴 종이의 **자산 · 위치 · 크기 · 기울기**가 달라진다.
- 별 · 먼지 · 혜성 꼬리는 찢긴 경계 **밖으로도** 새어 나온다.
- 클릭하면 약 **4초** 동안 종이 밖의 별가루가 구멍으로 빨려 들어가고 성운 막이 열린다.
- `prefers-reduced-motion`에서는 짧은 페이드만 쓴다.
- 우주에서 v2로 돌아온 뒤에도 진입점은 다시 살아 있어야 한다(`pageshow` · `visibilitychange` 리셋).

## 6. 은하수 연도 메뉴 (#173)

연도 버튼을 나열하지 않고 **은하수 띠 위의 세 밝은 점**으로 둔다.
선택한 연도가 밝아지고 나머지는 먼지로 가라앉는다. 좁은 화면에서는 띠가 세로로 선다.

## 7. 성장 별자리 (#59)

월별 기록을 전부 나열하지 않고 굵직한 성장 사건만 잇는다.
GitHub Rank `C → C+ → B- → B → B+ → A- → A` 상승 궤적을 하나의 사슬로 표현한다.

## 8. 이스터에그 (#119)

사전 안내 · 힌트 · 잠금 해제 설명을 화면에 두지 않는다.

| 이름 | 조건 |
|---|---|
| 뱀주인자리 | 2026 · 2025 · 2024를 모두 본 뒤 나타나는 이름 없는 13번째 별을 누른다 |
| 카피바라 | 5–11초에 한 번 지나가는 혜성을 지나가는 동안 누른다 |
| 일식 | 성운의 달무리 위에 포인터를 3초간 멈춘다 |
| 제51구역 | 성도 바깥의 이름 없는 불안정한 별을 **끌어서** 경계 밖 깨진 궤도에 놓는다 |

제51구역은 일반 메뉴 · 연도 메뉴 · 실패 목록에 이름을 노출하지 않는다.
내부에는 BrawlCraft를 격리 기록으로 둔다. 실패 원인은 항목을 연 뒤에만 보인다.

## 9. 사운드 — 미확정 (#232)

**아직 확정되지 않았다.** 확정된 세 자리만 연결하고 나머지는 무음이다.

| 자리 | 음원 | 상태 |
|---|---|---|
| 연도 전환 | `SFX-04 A` | 확정 |
| 별 선택 | `SFX-05 A` | 확정 |
| 상세 진입 | `SFX-06 B` | 확정 |
| 제51구역 해금 · 뱀주인자리 · 일식 | 2차 견본 파일 | **미확정 · 임시 연결** |
| 그 외 전부 | — | 무음 |

- 자동 재생하지 않는다. 사용자의 첫 조작 이후에만 소리가 난다.
- 음소거 버튼은 **소리가 한 번 난 뒤에** 나타난다(사전 예고 금지 원칙).
- 음원은 `../v3-constellation-prototypes/assets/audio/`를 그대로 참조한다. 파일을 복제하지 않는다.

## 10. 접근성 · 성능

- 성운 하늘은 오프스크린 캔버스에 한 번 그려 캐시한다. 매 프레임 다시 그리는 것은 천체 10여 개뿐이다.
- 탭이 보이지 않거나 `prefers-reduced-motion`이면 루프를 돌리지 않는다. 상호작용 시점에만 한 장을 다시 그린다.
- 모든 천체는 실제 `button`이다. 탭 순회 · Enter/Space · 방향키 조작이 된다. 최소 44px 터치 영역.
- 상태는 `aria-label`로만 말한다. 화면 글자로 쓰지 않는다.
- 개발자 도구 · 우클릭 · 드래그 · 텍스트 선택을 차단하지 않는다.
