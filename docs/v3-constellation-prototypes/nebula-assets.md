# 「차가운 성운」 시안 자산

시안 페이지는 배경과 소리를 브라우저에서 실시간으로 만들기 때문에, 그대로 두면
저장소에 이미지도 오디오도 남지 않는다. 사용자 지시에 따라 **화면과 소리를 실제
파일로 뽑아 여기에 남긴다.** 채택된 것과 폐기된 것을 모두 남긴다.

관련: 이슈 #114, Draft PR #171

---

## 0-1. 2026-08-21 이슈 #114 마지막 코멘트 반영 (v3 별도 Draft PR)

PR #171 이후 새 브랜치·새 Draft PR에서 진행한 항목이다. 범위는 `docs/v3-constellation-prototypes/`
안으로 한정했고, 운영 파일은 건드리지 않았다.

- **연도 성도 겹침 회귀** — `nebula.js`의 `resolveInteractiveCollisions()`가 폴드·모바일에서
  72회 시도 안에 자리를 못 찾고 멈추는 경우가 있었다. 폴드·모바일은 시도 횟수와 충돌 여백을
  넓혔다(`attempts`, `gap`).
- **카드를 열면 별자리가 움직이던 문제** — 카드가 펼쳐지며 라벨 충돌 회피 좌표(`body.x/y`)가
  옮겨지는데, 캔버스가 그 좌표를 그대로 별·연결선 위치로도 썼다. 별·선 전용 고정 좌표
  `body.baseX/baseY`를 따로 두어, 라벨만 옮겨 가고 성도는 카드 개폐와 무관하게 고정되게 했다.
- **v2 복귀 뒤 진입점이 사라지던 문제** — `initGateway()`의 클릭 핸들러가 `gate.disabled = true`를
  설정한 뒤 되돌리는 코드가 없었다. 뒤로 가기(bfcache 복원)나 탭 재방문 시 진입점이 영구히
  비활성 상태로 남았다. `pageshow`(persisted)와 `visibilitychange`에서 상태를 리셋한다.
- **v2→v3 진입 전환 4초, 새 전환음** — 기존 1.2초를 약 4초로 늘렸다. 상세/우주 진입에 쓰는
  SFX-06 B(세 음 타건)를 그대로 재사용하지 않고, `playGatewayEnterSfx()`에서 저역 스웰 + 연속
  상승 글리산도로 새로 합성한 SFX-14(비확정 후보)를 v2→v3 게이트웨이 클릭에만 연결했다.
  다른 화면의 SFX-06 B 사용(상세 페이지 이동)은 그대로 둔다.
- **사운드 3차 판정 반영** — 아래 §2 판정 현황 표와 `nebula-sound.html`에 3차 판정을 함께
  기록했다. 실제 런타임에 연결된 것은 여전히 SFX-04 A · SFX-05 A · SFX-06 B뿐이고, 새로
  추가한 SFX-14(게이트웨이 전환)만 예외적으로 연결했지만 이 역시 확정이 아니라
  사용자 청취 판정 대기 상태인 후보로 문서화했다.

## 0-2. 2026-08-21 이슈 #114 5차 라운드 반영

같은 브랜치·같은 Draft PR #179 위에 이어서 진행한 5차 항목이다. 4차까지 확정된
`SFX-04 A`(연도 전환) · `SFX-05 A`(별 선택) · `SFX-06 B`(상세 진입)는 손대지 않았다.

- **SFX-05/06 결 유지 변주 무작위 순환 연결** — 확정안을 대체하지 않고, 같은 결의
  변주(`SFX-05 A2/A3`, `SFX-06 B2/B3`)를 새로 합성해 `nebula.js`의
  `SELECT_SFX_VARIANTS`/`ENTER_SFX_VARIANTS`에 확정안과 함께 등록했다. 별 선택·상세
  이동마다 `playRotatingSfx()`가 목록 중 하나를 무작위로 골라 재생한다.
  `SFX-01`/`SFX-11`처럼 이전 라운드에 판정만 남기고 아직 연결하지 않았던 무작위
  순환 패턴을 실제로 처음 배선한 사례다. `SFX-06`의 실제 트리거는 `nebula.js`
  안에서 확인한 상세 이동 클릭 한 곳뿐이며, 별도의 우주 진입 지점에서는 쓰이지
  않는다(우주 진입 트리거는 SFX-14 계열).
- **SFX-08/12/13 완전히 새 방향** — 4차 후보(R2/R3, R/R2)까지 전부 원안의 연장으로
  판단해 폐기 표시하고, 각 상황의 역할에 맞춰 처음부터 다시 짰다. SFX-08(초신성
  잔해)은 저역 충격 대신 부서지는 유리·결정 파편, SFX-12(카피바라 이스터에그)는
  스치는 바람 대신 여리고 작은 타건, SFX-13(일식)은 몸통을 더하는 대신 정적을
  앞세우는 방향으로 바꿨다. 모두 `nebula-sound.html` 갤러리에만 있고 런타임에는
  연결하지 않았다.
- **SFX-14 후속(게이트웨이 전환음) 재작업** — 4차 A(저역 스웰 + 상승 글리산도)를
  불만족 판정으로 보고, 같은 스웰·글리산도 골격을 반복하지 않는 세 방향(G1 종이
  마찰, G2 낮은 공명+정적, G3 별가루가 모이는 결정)을 새로 만들었다. 갤러리와
  `nebula-gateway.html`의 새 비교판에서만 미리들을 수 있고, 런타임 기본값
  (`playGatewayEnterSfx()`)은 아직 4차 A 그대로 둔 채 바꾸지 않았다.
- **게이트웨이 진입 연출 후보 비교판** — 기존 진입점(`.gate-slot`)의 실제 동작은
  그대로 두고, `nebula-gateway.html`에 별도의 미리보기판을 추가했다. 기존 "찢긴
  종이" 외에 시각 은유가 완전히 다른 두 후보(조리개 개방, 잉크 번짐)를 캔버스로
  구현해 버튼으로 트리거·비교할 수 있게 했고, 위 SFX-14 후속 소리 후보와 짝지어
  재생할 수 있다. `prefers-reduced-motion`이면 즉시 종료 상태로 넘어간다.
- **폴드 11성 레이아웃 분리** — `nebula.js`의 `FOLD_YEAR[11]`이 균일 간격(.060)
  하나의 무리로만 짜여 있어 좁은 세로 폭에서 충돌 해소 재시도가 빠듯했다. 여백을
  더 넓히는 대신 가까운 무리(6개)/먼 무리(5개)로 나누고, 두 무리 사이에만
  훨씬 큰 간격(.165)을 둬 구조 자체를 분리했다.
- 이 회차는 오프라인 WAV(`assets/audio/`)를 다시 렌더하지 않았다. 새 후보는 모두
  `nebula-sound.html`/`nebula-gateway.html`의 Web Audio 합성 재생 버튼으로만
  비교 가능하다.

  방향)를 선택. 길이를 1~1.5초로 크게 줄인 Q1·Q2·Q3로 다시 짰다.
- **SFX-14 접근 자체 재정의(효과음 → 음악)** — 6차 H1~H3(리듬형·도플러형·분열형
  효과음)도 "효과음 말고 음악"이라는 판정으로 전부 폐기. MUS-01과 같은 계열
  (pad/bell 합성)이되 "떠오르며 나아가는" 상승 진행을 가진 짧은 음악(4~6초)

  6초로 확장한 후보(`m1a6`)를 추가하고, 갤러리에서 4.5·5·7·9초보다 먼저 보이는
  기준 후보로 강조했다.
- **게이트웨이 진입 연출 완전 재브레인스토밍** — "진입 연출 후보도 다 별로야,
  어떻게 구현할지 같이 생각해보자"는 요청에 따라 참고 레퍼런스 없이 완전히
  새로운 세 은유를 제안했다. 6차까지의 여섯 후보(찢긴 종이[운영 기본]·조리개
  개방·잉크 번짐·초점 풀림·장막 걷힘·불씨 번짐) 중 초점 풀림·장막 걷힘·불씨
  번짐도 전부 반려하고, **종이 재구성(coalesce, 흩어진 종이 조각이 별자리로
  모임)** · **유리 아래 번짐(loupe, 확대경으로 들여다보는 굴절 원형 창)** ·
  **빛의 확장(point, 한 점의 빛이 지수적으로 커져 화면을 삼킴)** 세 후보를
  `nebula-gateway.html`에 실제 동작하는 canvas 코드로 구현했다.
- **진입점/성장 별자리 "깨짐" 제보 조사** — "우주 진입점이 깨져 있다·이미지 안
  보임·반응 없음·성장 별자리 안 보임"이라는 제보를 실제 저장소 파일 기준으로
  독립 조사했다. `nebula-gateway.html`의 `data-gate*` 마크업은 `nebula.js`
  `initGateway()`가 찾는 selector와 정확히 일치하고, 이미지 경로
  `assets/gateway/torn-portal-*.png`는 파일 위치 기준 상대 경로로 실제 자산과
  맞으며, 클릭 리스너는 DOM 참조 확보 후에만 등록된다. `nebula-transit.html`의
  `source: "../../projects.json"`도 저장소 루트 `projects.json`을 정확히
  가리키고, `loadProjects()`는 `fetch` 실패 시 항상 `FALLBACK` 데이터로
  대체하므로 빈 화면이 나올 경로가 없다. **결론: 실제 파일은 정상이며, 제보한
  증상은 외부 미리보기 번들러 도구의 버그였다(이미 그 도구 쪽에서 수정됨,
  이 저장소 범위 밖).** 실제 파일에는 수정하지 않았다 — 고칠 결함이 없었다.
- 이 회차도 오프라인 WAV를 다시 렌더하지 않았다. 새 후보는 모두 Web Audio 합성
  재생 버튼으로만 비교 가능하다.

## 0. 2026-08-21 사용자 결정 반영

- 홈 진입점은 홈 섹션 안에 유지한다. 지표 칸의 고정 위젯이 아니라, 새로고침마다 자산·위치·크기·기울기가 달라지는 종이 찢김으로 둔다.
- 찢김은 v2의 따뜻한 노트 종이와 같은 계열의 섬유·말린 가장자리·부드러운 그림자를 사용한다. 별자리·별·혜성 꼬리는 경계 밖까지 나오고, 클릭 때는 그 찢김을 중심으로 우주가 확장된다.
- 우주 화면에서 v2로 돌아가는 경로는 시각 텍스트 없는 작은 빈 포스트잇 하나로 둔다.
- 우주 진입점에는 별도의 영문 이름표를 두지 않는다.
- 연도 버튼을 누르면 기존 별자리가 사라지고 새 별자리가 들어오는 전환 애니메이션을 쓴다. 프로젝트는 사용자가 정한 2026·2025·2024 완료·실패·진행 중 순서로 시안 안에서만 분리한다.
- 사운드 맵은 현재 2차 견본이다. 다만 2차에서 확정된 `SFX-04 A`(연도 전환), `SFX-05 A`(별 선택), `SFX-06 B`(상세·우주 진입)는 실제 상호작용에 연결한다. 나머지는 확정된 척 연결하지 않는다.
- `SFX-01 B`와 `SFX-11 A`는 추천이며 아직 택일 대기다. `MUS-01`은 A 구조를 유지한 채 5·7·9초 후보를 다시 만든 뒤 길이를 정한다.
- #114의 재작업 대상은 사운드 맵에서 실제 비교할 수 있게 새 합성 후보를 추가했다. `SFX-03 C′`(종 제거), `SFX-07 C′`, `SFX-08 R`, `SFX-09 R`, `SFX-12 R`, `MUS-01 5·7·9초`이며, 모두 사용자 판정 전에는 전환 화면에 연결하지 않는다.
- 폴드·폰·태블릿·노트북은 같은 좌표를 억지로 축소하지 않는다. 폴드/모바일/태블릿/와이드 성도를 따로 두고, 카드가 펼쳐진 높이까지 다시 계산해 다른 클릭 영역과의 충돌을 피한다.
- 홈 진입은 `SFX-06 B`와 함께 찢김 밖의 별가루와 궤적이 안쪽으로 빨려 들어가고, 성운 막이 열리는 1.2초 전환으로 바꾼다.

이번 회차는 로컬 브라우저 미리보기에서 연도 전환, 새로고침마다 달라지는 찢김, 데스크톱·태블릿·모바일 성도 배치를 확인한다.

### 캡처에서 드러난 것

자산을 만들며 관찰된 사항이다. **독립 검증이 아니라 캡처 중 눈에 띈 것**이며,
브라우저 QA는 별도로 필요하다.

- **초신성 잔해가 터진 별로 안 읽힌다.** 껍질의 요동 계수가 커서 꽃잎이나 찌그러진
  봉투처럼 보인다. `nebula.js`의 `remnant()`에서 `wob` 진폭을 줄이고 끊긴 구간을
  더 크게 벌려야 한다.
- **진행 중 천체의 강착 원반이 지나치게 크다.** 오른쪽 성운 위로 번져 별 자체가
  묻힌다. 원반 반경을 줄이고 코어 대비를 올려야 한다.
- **성운의 밝은 결이 대각선 얼룩으로 튄다.** 성운의 결이 아니라 렌즈 플레어처럼 보인다.
- **라이트 모드 전환 화면이 우주로 읽히기에 약하다.** 첫 화면(KV-1)은 승인되었지만
  전환 화면 쪽은 성운 농도가 더 낮아 밝은 회색 화면에 가깝다.
- **첫 로드가 느리면 화면이 빈다.** `projects.json` 로드 전에는 아무것도 그리지 않는다.
  실제 캡처에서 6초 안에 로드가 끝나지 않아 이름만 남은 장면이 나왔다. 로딩 중
  상태가 필요하다.
- 긴 프로젝트 이름(`멈춰！ — 2026 U-CAST …`)이 두 줄로 넘친다. 라벨 최대 폭 조정이 필요하다.

## 2. 오디오 — `assets/audio/`

`nebula-sound.html`의 39개 레시피를 그대로 오프라인 렌더한 것이다.
22.05kHz · 16bit · 모노 WAV. 큐마다 최대치를 맞춰 두어 나란히 비교할 수 있다.

재생성:

```bash
node tools/render-nebula-audio.js
```

브라우저판과 다른 점은 **잔향뿐**이다. 시안 페이지는 `ConvolverNode`를 쓰지만,
저장소 규칙상 Node 내장 모듈만 쓸 수 있어 렌더러는 콤·올패스 기반 잔향으로 대체했다.
음색과 길이는 같고 공간의 결만 조금 다르다.

그대로 따랐다. 위 파일명은 `nebula-sound.html`의 `s8r2/s8r3`, `s12r2/s12r3`,
`s13r/s13r2`, `s4a2/s4a3`, `m1a4`, `s14a` cue key와 1:1로 대응한다.

### 안 들린 이유

`볼륨 키우면 들려. 근데 같은 볼륨에서 잘 안 들린다는 거야.`

볼륨 설정이 아니라 주파수 구성 문제다. 사람 귀는 같은 진폭에서 저주파를 훨씬 작게
듣는다. SFX-02·07·08·13은 저역 중심인데 중역 성분을 넣지 않아 존재감이 사라졌다.
다음 회차에는 저역 소리마다 중역 몸통을 넣고 게인을 따로 잡는다. 전체 볼륨을
올리는 방식으로 해결하지 않는다.

### 라이선스

이 WAV들은 전부 코드로 합성한 것이며 외부 음원을 쓰지 않았다. 저장소 라이선스를 따른다.

실제 음원으로 교체할 경우 아래에서 **출처 표기 없이 상업적 사용이 가능한 것**만 쓴다.

- [Pixabay](https://pixabay.com/sound-effects/) — 출처 표기 불필요, 가입 없이 내려받기. 기본값으로 권장
- [Freesound](https://freesound.org/) — 라이선스가 섞여 있으므로 반드시 `CC0` 필터. 내려받기에 계정 필요
- [Mixkit](https://mixkit.co/free-sound-effects/) — 출처 표기 불필요, 가입 불필요
- [OpenGameArt](https://opengameart.org/content/cc0-sound-effects) — CC0 모음. UI 계열이 많다

## 3. 아직 만들지 않은 자산

### 카피바라 이미지

기존 생성 프롬프트(#114)는 폐기된 수묵 방향 기준(`달빛 연보라와 따뜻한 갈색, 종이 질감`)이라
그대로 쓸 수 없다. 「차가운 성운」에 맞춘 갱신본이다. 사용자가 ChatGPT로 생성해 전달하면
`assets/images/`에 넣는다.

> 투명 배경의 작은 카피바라 일러스트. 저채도 남보라와 청회색의 차가운 우주를 배경 없이,
> 오래된 금빛 빛을 한쪽 방향에서만 받는 옆모습. 화면 밖 오른쪽 위에 광원이 하나 있는 것처럼
> 한쪽만 밝고 반대쪽은 어둠에 잠길 것. 투명한 둥근 헬멧을 쓰되 우주복은 최소화.
> 몽환적이고 조용하며 살짝 쓸쓸한 정서. 네온, 순검정, 강한 글로우, 두꺼운 외곽선,
> 치비 과장, 텍스트, 로고, 배경, 다른 캐릭터는 제외. 반짝이 효과 금지.
> 작은 크기에서도 실루엣이 읽혀야 하며 사방에 충분한 투명 여백을 둘 것.
> 1:1 비율, 고해상도 PNG, transparent background.

용도: 모든 연도를 관측한 뒤 나타나는 조건형 혜성 이스터에그. 상시 노출 금지.

### 11초 음악

길이가 재검토 대상이므로(사용자 평가 `너무 길어`) 길이가 확정된 뒤 프롬프트를 확정한다.
Google의 Lyria 계열(Gemini API의 Lyria RealTime, MusicFX)은 짧은 효과음에는 맞지 않지만
무가사 인스트루멘털 곡에는 적합하다. 확정 후 `assets/audio/`에 넣고 `mus-01-*.wav`를 대체한다.

### 성장 별자리 · 제51구역 · 상세 페이지

아직 시안 자체가 없다. 만들어지면 같은 원칙으로 이미지와 소리를 여기에 남긴다.
