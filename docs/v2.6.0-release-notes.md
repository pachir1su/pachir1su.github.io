# v2.6.0 — Final Note

v2.5.0 이후의 UIUX 정리 릴리즈입니다. 기존 노트/인덱스 카드 컨셉은 유지하면서, 정보 전달에 도움이 되지 않는 장식과 중복 인터랙션을 걷어내고 재학 정보·연락처·메뉴·반응형 동작을 정리합니다.

## 주요 변경

- MBTI 섹션을 화면에서 제거합니다. (#118)
- 홈의 드래그/부유 프로그래밍 언어 장식과 치킨 모드를 제거합니다. (#119)
- 재학 표시를 `한국기술교육대학교 26학번`으로 통일하고 현재 재학 관계가 반영되도록 구조화 데이터를 정리합니다. (#121)
- 데스크톱·모바일 메뉴의 중복 Home 항목과 우측 플로팅 섹션 네비게이터를 제거해 메뉴를 단순화합니다. (#122)
- Hero 영역에 `capybara@koreatech.ac.kr` 연락처를 명확하게 노출합니다. (#114)
- 모바일·태블릿·PC에서 레이아웃을 보강하고 reduced-motion/포인터 능력을 존중합니다. (#123, #16)
- 정보 탐색에 필요하지 않은 홈 인터랙션을 줄이고 기존 카드·필터·언어·테마 동작은 유지합니다.

## 구현 상태

v2.6.0의 사용자-facing 변경은 `script.js`의 v2.6 호환 레이어를 통해 현재 페이지에 적용됩니다. 이 레이어는 기존 정적 마크업에서 MBTI·floating icon·중복 내비게이션을 제거하고, 재학 정보와 Hero 연락처를 런타임에서 정규화합니다.

정적 `index.html`/`style.css` 안에 남아 있는 이전 마크업·dead CSS를 통째로 다시 쓰는 작업은 v2.6.0 Release를 막는 변경으로 취급하지 않고 **v2.6.x Freeze/Refactor** 단계에서 실제 기기 QA와 함께 한 번에 정리합니다. 이는 사용자에게 노출되는 기능 차이가 아니라 소스 정리 부채입니다.

## v2.6.0 검증 기준

- `projects.json`을 프로젝트 카드의 단일 소스로 유지
- `BUILD:PROJECTS` 생성 영역 직접 수정 금지
- `node --check script.js`
- `node build.js` 실행 후 생성 결과 무변경 확인
- `node tools/verify-build.js`
- 공개 저장소에서 개발자 도구·우클릭·텍스트 선택 차단 금지
- 실제 브라우저/기기에서 확인하지 않은 항목은 QA 완료로 표시하지 않음
