# v2.6.0 — Final Note

v2.5.0 이후의 UIUX 정리 릴리즈입니다. 기존 노트/인덱스 카드 컨셉은 유지하면서, 정보 전달에 도움이 되지 않는 장식과 중복 인터랙션을 걷어내고 재학 정보·연락처·메뉴·반응형 동작을 정리합니다.

## 주요 변경

- MBTI 섹션과 관련 마크업/CSS를 완전히 제거합니다. (#118)
- 홈의 드래그/부유 프로그래밍 언어 장식과 치킨 모드를 제거합니다. (#119)
- 재학 정보를 `한국기술교육대학교 26학번`으로 통일하고 Person JSON-LD의 대학 관계를 현재 재학 의미인 `affiliation`으로 정리합니다. (#121)
- 데스크톱·모바일 메뉴의 중복 Home 항목과 우측 플로팅 섹션 네비게이터를 제거해 메뉴를 단순화합니다. (#122)
- Hero 영역에 `capybara@koreatech.ac.kr` 연락처를 명확하게 노출합니다. (#114)
- 1024px/640px 구간을 포함해 모바일·태블릿·PC 레이아웃을 보강하고 reduced-motion/포인터 능력을 존중합니다. (#123, #16)
- 위치 순서에 의존하던 내비게이션 번역 로직과 사용하지 않는 stale CSS/JS를 정리합니다.

## 검증 기준

최종화 과정에서 다음 검증을 통과해야만 소스 변경을 `main`에 반영합니다.

- `BUILD:PROJECTS` 생성 영역 불변 확인
- 제거 대상 MBTI/floating icon/chicken/section-nav 문자열 잔재 검사
- `node --check script.js`
- `node build.js` 실행 후 working tree 무변경 확인
- `node tools/verify-build.js`
- `git diff --check`
