# v3.0.0 — 별자리 공간

v2 노트 포트폴리오를 **교체하지 않는** 메이저 릴리즈입니다.
v2는 정보를 그대로 맡고, 그 옆에 세계관을 맡는 공간 하나가 새로 생깁니다.

두 공간은 홈에 뚫린 **찢긴 종이 구멍 하나**로만 이어집니다.
`포트폴리오니까 다 보여야 한다`와 `개성 있는 세계관`이 한 화면에서 충돌하던 문제가
이 분리로 사라집니다.

관련 이슈 — #114(디자인 컨셉 · UIUX) · #59(성장 타임라인) · #119(이스터에그)
· #123(적응형 UI) · #173(연도 메뉴) · #120(릴리즈 버전)

---

## 주요 변경

- **별자리 공간을 `/universe/`에 신설합니다.** 스크롤이 없습니다. 멀리서 하늘 전체가 보이고,
  구역을 누르면 카메라가 그리로 날아가 이름이 켜집니다. 빈 곳이나 `Esc`로 물러납니다.
  구역은 여섯 — 2026 · 2025 · 2024 · 궤적 · 표류 · 기록. (#114)
- **홈 히어로에 우주 진입점을 둡니다.** 새로고침마다 자산 · 위치 · 크기 · 기울기가 달라지는
  찢긴 종이 구멍이고, 누르면 약 4초 동안 별가루가 빨려 들어가며 문이 열립니다. (#114)
- **연도별 프로젝트를 별자리로 읽습니다.** 하늘 위에 놓인 연도 구역을 눌러 들어가고,
  그 해 완성한 프로젝트만 낡은 금빛 실선으로 이어집니다. 2026 오리온 · 2025 카시오페이아 ·
  2024 백조로 형태가 서로 겹치지 않습니다. 별자리는 실제 하늘의 종횡비를 지키므로
  어느 기기에서도 같은 모양입니다. (#173)
- **성장 과정을 별자리로 만듭니다.** 저장소에 근거가 남은 굵직한 사건 7개를 잇고,
  사건 사이의 선 6개가 GitHub Rank `C → C+ → B- → B → B+ → A- → A`와 맞물립니다. (#59)
- **진행 중 · 중단 · 실패 · 지연을 지우지 않습니다.** 화면에 상태 글자를 쓰지 않고
  원시성 · 점화 실패 · 초신성 잔해 · 궤도 이탈이라는 형태로만 구분합니다. (#114)
- **이스터에그를 넣습니다.** 세 해를 모두 들르면 이름 없는 별이 생기고, 그 별에서
  뱀주인자리가 그어지고, 다 그어진 뒤에 격리된 기록이 열립니다.
  발동 전에도 후에도 조건을 설명하지 않습니다. (#119)
- **적응형 UI를 폭이 아니라 지도로 다룹니다.** 세로로 긴 화면에서는 구역이 아래로
  내려가는 지도로 다시 놓입니다. **구역을 빼거나 목록으로 강등하지 않습니다.**
  조작은 어느 폭에서도 같습니다 — 누르면 날아갑니다. (#10 · #123)
- **별 이름표가 겹치지 않습니다.** 이름표 폭을 재서 별의 바깥쪽으로 뻗고, 화면 밖으로
  나가거나 다른 글과 겹치면 반대쪽으로 넘기거나 한 줄씩 밀어냅니다. (#163)

## 시각 언어

#114의 취향 캘리브레이션에서 직접 고른 값만 씁니다.

| 축 | 값 |
|---|---|
| 배경 | 엷은 성운 — 화면 밖 오른쪽 위 방향광 · 어두운 먼지 띠 · 입자 2층 |
| 별 | 3계층 — 먼 먼지 340 / 일반 별 72(순수한 점) / 별자리 별(옅은 달무리) |
| 선 | 낡은 금빛 실선. 굵기 1.1px · 불투명도 0.6 안팎 |
| 서체 | IBM Plex Sans KR. 이름은 얇은 200을 크게, 영문은 자간을 넓게 |
| 구도 | 왼쪽 아래 이름 · 오른쪽 위 별자리 (카메라가 그 사각형에 하늘을 맞춥니다) |
| 팔레트 | 라이트 `#e8eaf2` + `#706994` / 다크 `#11151d` + `#968dbb` / 금빛 `#a9914d` |
| 테마 | 수동 토글 없음. `prefers-color-scheme`만 따릅니다 |

폐기한 방향(수묵 · 그레인 필드 · 점선 · 지평선 구도 · 명조체 · 이름표 `CONSTELLATION`)과
그 근거는 `docs/v3-universe/README.md`와 `docs/design-concept-v3.md`에 남습니다.

## v2에 미치는 영향

운영 `index.html`에 들어간 것은 **세 곳뿐**입니다.

```html
<link rel="stylesheet" href="universe/gate.css" />   <!-- head -->
<div class="v3-gate-host" data-gate-host></div>      <!-- .hero 안 -->
<script defer src="universe/gate.js"></script>       <!-- body 끝 -->
```

- `style.css` · `script.js` · `projects.json` · `build.js`와 `BUILD:PROJECTS` 생성 영역은
  변경하지 않습니다. 프로젝트 카드 렌더 결과가 달라지지 않습니다.
- `gate.css`는 토큰과 전역 요소 규칙을 두지 않습니다. `.v3-gate` 계열 선택자만 쓰므로
  `style.css`의 `--ink` · `--gold` · `--line`을 덮지 않습니다.
- `gate.js`는 홀로 섭니다. 홈이 우주 엔진(`sky.js` + `universe.js`)을 받지 않습니다.
- `gate.js`가 실패하면 진입점 자리는 빈 칸으로 남고 히어로는 그대로 동작합니다.

## 성능

- 홈이 새로 받는 것은 `gate.css` 2.3KB + `gate.js` 16KB + 찢김 마스크 한 장(25~44KB)입니다.
- 찢김 원본은 한 장이 1.7~2.2MB인 RGBA PNG입니다. 진입점 렌더가 실제로 쓰는 것은 알파뿐이라
  `tools/build-gateway-masks.js`가 알파만 뽑아 회색조+알파 PNG로 다시 씁니다.
  **2.11MB → 42.7KB.** Node 내장 `zlib`만 쓰고 외부 패키지를 설치하지 않습니다.
- **상시 `requestAnimationFrame`을 돌리지 않습니다.** 카메라가 움직이는 동안과 연출이
  도는 동안에만 프레임을 요청하고, 멈추면 루프도 멈춥니다(#113 P1-1 회귀 금지).
- 첫 한 장과 상태 진행은 루프에 맡기지 않습니다. `paintNow()`가 즉시 한 장을 완성하고,
  진행 시점은 `setTimeout`이 정합니다. 프레임이 굶어도 화면과 상태가 멈추지 않습니다.
- 효과음은 첫 재생 순간에 `Audio` 객체를 만듭니다. 소리를 한 번도 내지 않으면 파일을 받지 않습니다.

## 접근성

- 모든 천체는 실제 `button`입니다. 탭 순회 · Enter/Space · 방향키가 되고 최소 44px 터치 영역을 가집니다.
- 상태는 `aria-label`로만 말합니다. 화면 글자로 쓰지 않습니다.
- 열린 카드와 격리 기록은 `Esc`로 닫히고, 격리 기록은 `role="dialog"`로 포커스를 받습니다.
- 하늘에 걸린 이름표는 줄여 쓰더라도 `aria-label`에는 온전한 이름이 남습니다.
- JavaScript 없이 열면 `<noscript>`가 홈의 프로젝트 목록으로 안내합니다.
- 개발자 도구 · 우클릭 · 드래그 · 텍스트 선택을 차단하지 않습니다.

## 릴리즈 순서

이 릴리즈는 v2의 어떤 화면도 되돌리지 않으므로 v2 마감 작업과 충돌하지 않지만,

Git tag와 GitHub Release는 만들지 않습니다(`AGENTS.md`).
