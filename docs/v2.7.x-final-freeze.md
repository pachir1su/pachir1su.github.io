### 성능 판단

#16 `코드 최적화`는 **닫지 않습니다.** 기능·반응형 회귀는 없지만 Lighthouse 성능 점수와 모바일 LCP를 보면 추가 최적화 여지가 명확합니다.

Lighthouse에서 크게 잡힌 항목은 다음과 같습니다.

- 초기 렌더를 막는 CSS/웹폰트
  - Google Fonts
  - Font Awesome
  - Devicons
  - AOS CSS
  - 루트 `style.css`
- unused CSS 추정 절감량: 약 183–184 KiB
- Devicon font 전송량: 약 657 KiB
- 모바일 main-thread work: 약 2.3 s
- 모바일 LCP element는 hero 설명 문단이며, LCP 시간의 약 90%가 render delay로 측정됨

따라서 Final Freeze에서 위험한 대규모 스타일/폰트 교체를 넣지 않고, 위 항목은 #16의 후속 최적화 범위로 유지합니다.
