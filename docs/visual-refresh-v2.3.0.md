# v2.3.0 — 시각 개편 (노트 컨셉 유지)

v2.1.0 · v2.2.0 은 문구와 정보구조를 고쳤고 시각 디자인은 건드리지 않았다.
그래서 "위치만 바뀐 것 같다"는 지적이 나왔고, 실제로 그랬다. CSS 는 466줄을
지우고 194줄을 넣었지만 그 194줄은 전부 삭제된 규칙의 대체이거나 대비 보정이었다.

이 문서는 v2.3.0 에서 **디자인 컨셉은 그대로 두고 시각 표현만** 바꾼 내용을
남긴다. 컨셉 자체를 바꾸는 작업은 v3.0.0 (`docs/design-concept-v3.md`) 이다.

---

## 1. 근본 원인 — 카드가 곧 노트 페이지였다

기존 카드 프리미티브는 `.about-card, .skill-card, .award-card, .project-card`
한 덩어리에 배경 레이어 6장을 깔았다.

| 레이어 | 내용 |
|---|---|
| 1 | 마스킹 테이프 SVG |
| 2 | 빨간 마진선 |
| 3–5 | 펀치홀 3개 (`radial-gradient` × 3) |
| 6 | 괘선 `repeating-linear-gradient` |

카드 한 장이 노트 페이지 한 장을 완전히 재현했다는 뜻이다. 문제는 수량이다.

- 프로젝트 27 + 역량 6 + 수상 4 + About 1 = **38장**
- 한 화면에 3~4장이 동시에 보이므로, 화면이 "노트 페이지 여러 장이 겹친 것"이 된다
- 펀치홀을 피하려고 **모든 카드가 좌측 패딩 64px** 를 버렸다 (모바일 52px)
- 카드끼리 구분이 안 되니 위계가 사라진다

### 바꾼 것

노트 크롬을 **문서 단위로 한 번만** 그린다.

- `.page-binding` — 좌측 고정 레일. 빨간 마진선 + 펀치홀을 문서 전체에 한 줄로.
  컨테이너가 1160px 이라 그보다 넓은 화면에는 좌우 여백이 남고, 레일은 그
  여백에만 놓이므로 **본문 레이아웃은 밀리지 않는다.** 1280px 미만에서는 숨긴다.
- 카드가 갖는 장식은 **상단 색 띠 하나**(`--tab`). 좌측 패딩 64px → 24px 회수.

## 2. 위치로 색을 정하던 규칙 폐기

같은 카드를 세 곳에서 다른 방식으로 색칠하고 있었다.

```css
/* 제거 */
.skill-card:nth-child(4n+1) { border-top: 3px solid var(--red); }    /* 4색 순환 */
.project-card:nth-child(5n+1)::after { background: var(--red); }      /* 5색 순환 */
.skill-card:nth-child(5n+1)::after { color: var(--red-text); }        /* 스티커 5색 순환 */
```

다섯 번째 카드가 잉크색인 데에는 아무 의미가 없다 — **위치가 정한 색**이다.
카드를 하나 추가하면 그 뒤 카드의 색이 전부 밀린다.

색은 의미에만 쓴다.

| 대상 | 색 | 근거 |
|---|---|---|
| `.about-card` | cyan | 비전 섹션 |
| `.skill-card` | gold | 역량 섹션 |
| `.award-card` | bronze | 수상 섹션 |
| `.project-card` | red | 기본 |
| `.project-wip` | gold | 진행 중 |
| `.project-failed` | 회색 | 중단 |

## 3. 겹쳐 그리던 규칙 정리

스타일시트가 이슈마다 하단에 번호 블록(`39. 견출지`, `41. 메모지`, `42. 견출지`…)을
덧붙이는 방식으로 자라서, 같은 요소를 여러 블록이 각각 손대고 있었다.

| 증상 | 원인 | 조치 |
|---|---|---|
| 섹션 헤더 밑줄 2줄 | `#8 ::after` + `#39 border-bottom` | `::after` 하나로 |
| 카드 상단 띠 2줄 | `#9 ::before` + `#41 border-top` | `::before` 하나로 |
| 테이프 호버 위치 | `#29` — 테이프가 사라져 대상 없음 | 제거 |
| `.project-card::after { left: 64px }` | 사라진 펀치홀 자리 | 제거 |

## 4. 타입 · 간격 · 본문 폭

컴포넌트마다 `0.78 / 0.82 / 0.88 / 0.98 / 1.05rem` 을 제각기 선언해서
위계가 없었다. 7단계 스케일과 4px 배수 간격 스케일을 토큰으로 고정했다.

산문에는 `--measure: 62ch` 상한을 걸었다. 1440px 화면에서 About 본문 한 줄이
100자를 넘게 흐르던 문제를 문단 폭 자체로 막는다. `.about-card` 도 780px 로
묶어 글 폭에 맞췄다 — 그러지 않으면 카드 오른쪽 절반이 빈 종이로 남는다.

---

## 5. 히어로

- `max-width: 820px` 가운데 정렬이라 본문 그리드와 어긋난 위치에서 시작하고,
  1440px 화면에서는 오른쪽 절반이 통째로 비었다 → 2단 그리드. 포스트잇 지표를
  오른쪽 열로 세운다.
- 부유 아이콘 `.fi` 96px → 48px, 이중 테두리 → 한 겹, `opacity` 0.85 → 0.5.
  지름이 본문 글자의 6배라 이름보다 먼저 시선을 가져갔고, 아이콘 폰트가 늦게
  뜨면 빈 고리로만 보인다. 위치도 본문 열 바깥으로 밀었다.
- 글자 뒤에 깔던 색 블록(이름 · 섹션 제목)을 밑줄로 내렸다. 배경색이 글자와
  겹치면 대비가 떨어진다.

---

## 6. 남은 위험

- `.taped` 클래스는 `script.js` 가 여전히 붙이고, `icon-pop` 애니메이션이
  거기 걸려 있다. 이름만 테이프이고 동작은 아이콘 pop 이라 주석을 고쳤지만
  클래스명 자체는 그대로 두었다 — 이름 변경은 JS 동시 수정이 필요하다.
- 스타일시트의 번호 블록 구조(1~56, 번호 중복 있음)는 그대로다. 이번에는
  새 카드 프리미티브와 **직접 충돌하는 블록만** 정리했다. 전체 재편은 별건.
- `--measure` 는 About 본문과 히어로 설명에만 적용했다. 프로젝트 카드 본문은
  카드 폭이 이미 좁아 상한이 필요 없다.
