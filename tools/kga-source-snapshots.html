DESIGN PROPOSALS

공개 웹 디자인 시안

현행 공개 웹(web/index.html · web/assets/style.css)의 UI/UX 진단 결과와, 그에 따른 개선 시안 네 가지입니다. KOREATECH 남색·주황 브랜드와 라이트·다크 규칙을 유지합니다.

시안 A

정돈안

지금 화면 구조를 그대로 두고 흩어진 수치만 스케일로 묶습니다.

  • 글자 크기 26종 → 6단계
  • 모서리 15종 → 4단계
  • 터치 타깃 38px → 44px
시안 B

여백형

그림자를 걷어내고 1px 선과 여백만으로 구분합니다.

시안 C

밀도형

히어로를 걷어내고 첫 화면에 실제 정보를 더 채우는 안입니다.

시안 D

모바일 우선

폰 화면을 기준 화면으로 잡고 데스크톱을 확장으로 둡니다.
